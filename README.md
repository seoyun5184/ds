# 평택 상담데이터 대시보드

평택소사벌알짜공인중개사사무소 상담 브리핑용 GitHub Pages 사이트입니다.

## 주요 기능

- 평택시 법정동, 읍, 면 선택
- 선택 지역 아파트 목록 표시
- 실거래 Top 10 및 거래유형별 그래프
- 무료 OpenStreetMap 지도 표시
- 상담데이터 브라우저 저장 및 엑셀 다운로드

## 공공데이터 인증키

공개 GitHub 저장소에는 인증키를 넣지 않았습니다. 사이트 화면의 `공공데이터 인증키` 입력칸에 키를 넣으면 해당 브라우저에만 저장됩니다.

## 로컬 실행본

엑셀 파일을 PC 폴더에 직접 저장하는 로컬 실행본은 `C:\Users\user\Desktop\평택상담대시보드_배포용.zip`에 있습니다.
