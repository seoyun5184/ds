# 평택 상담데이터 대시보드

평택소사벌알짜공인중개사사무소 박서윤 대표님의 상담 브리핑용 사이트입니다.

## 주요 기능

- 평택시 법정동, 읍, 면 선택
- 동·읍·면 드롭다운에서 `가재동(735건)` 같은 건수 표기 제거
- 공공데이터 실거래 API 조회 후 선택 지역 아파트 목록 표시
- 읍·면 하위 리 단위 응답을 상위 읍·면으로 자동 분류
- 주간, 월간, 년간 기간 선택
- 거래유형별 막대그래프
- Top 18 관심단지 순위 버전: 총점, 거래량, 평균가
- 관심단지 가격 비교선과 현재 가격변경 표시
- 삼성전자, 역, 학교, 공원, 상권 거리 기반 입지 점수와 상세 중개 브리핑
- 무료 OpenStreetMap 지도 표시
- 상담데이터 브라우저 저장 및 엑셀 다운로드

## 공공데이터 인증키 처리

상담 화면에서 인증키를 입력하지 않도록 구성했습니다.

공개 GitHub Pages는 정적 호스팅이라 인증키를 안전하게 숨길 수 없습니다. 그래서 인증키는 화면이나 공개 코드에 넣지 않고, `/public-data` 서버 프록시가 있는 실행 환경에서 자동 조회하도록 구성했습니다.

로컬 실행본은 `server.ps1` 프록시가 공공데이터를 대신 호출하므로 상담자가 화면에 키를 입력하지 않아도 됩니다. Vercel 같은 서버형 배포를 사용할 때도 같은 방식으로 서버 환경변수 또는 서버 내부 설정에 키를 넣어야 합니다.

## 로컬 실행본

PC 폴더에 상담 데이터와 실거래 저장 데이터를 직접 저장하는 로컬 실행본은 바탕화면의 `C:\Users\user\Desktop\randing page` 폴더와 `C:\Users\user\Desktop\평택상담대시보드_배포용.zip`에 있습니다.
